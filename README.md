A token launch radar: it ranks the snapshot's pre-token DeFi protocols by an implied value read off a size curve fitted and tested out of sample, prints honest token odds from the peers' own record, and gives every row a costed farm plan. Built by an AI agent for make.fun's "Build the best token launch radar" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <kit>/input/snapshot.json
```
